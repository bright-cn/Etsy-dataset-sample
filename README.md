# Etsy 数据集样本

<h2>包含 1001 款 Etsy 商品的样本数据集</h2>

![Etsy 商品数据集标题图](https://github.com/bright-cn/Etsy-dataset-sample/blob/main/Etsy-dataset.png)

一个包含 1000 多条记录的 Etsy 商品数据集样本。该数据集使用 <b>Bright Data API</b> 提取。

<h2>Etsy 商品数据集中包含的部分数据点：</h2>

* ```url```：商品的 URL 或链接  
* ```product_id```：商品的唯一标识符  
* ```listing_inventory_id```：商品信息的库存标识符  
* ```title```：商品的标题或名称  
* ```rating```：商品的平均评分  
* ```reviews_count_shop```：店铺的评论数量  
* ```reviews_count_item```：商品的评论数量  
* ```initial_price```：商品的初始/原始价格  
* ```discount_percentage```：商品提供的折扣  
* ```final_price```：商品折扣后的最终价格  
* ```currency```：定价所使用的货币  
* ```images```：商品图片  
* ```breadcrumbs```：商品的导航面包屑  
* ```root_category```：商品的根类别  
* ```seller_name```：卖家或供应商的名称  
* ```seller_shop_name```：卖家店铺的名称  
* ```seller_response```：卖家的回复  
* ```item_details```：商品详情  
* ```shipping_return_policies```：配送和退货政策  
* ```product_specifications```：商品规格  
* ```related_searches```：与商品相关的搜索  
* ```faqs```：关于商品的常见问题  
* ```category_tree```：商品的类别树  
* ```top_reviews```：商品的热门评论  
* ```photos_from_reviews```：评论中的照片  
* ```listed_date```：商品的上架日期   

以及更多数据。

这是“Etsy 商品”数据集的样本子集，完整数据集包含超过 <b>810 万条记录</b>。

可用的数据集文件格式：<b>JSON、NDJSON、JSON Lines、CSV 或 Parquet。还可选择将文件压缩为 .gz 格式</b>。

数据集交付方式选项：<b>电子邮件、API 下载、Webhook、Amazon S3、Google Cloud Storage、Google Cloud Pub/Sub、Microsoft Azure、Snowflake、SFTP</b>。

更新频率：<b>一次性、每日、每周、每月、每季度或自定义</b>。

可在已提取数据点的基础上添加数据增强：<b>根据请求提供。</b>

<h2>Etsy 商品数据集有哪些使用场景？</h2>

<h3>1. 市场分析</h3>
利用 Etsy 数据集分析客户人口统计特征、购买模式、商品偏好、评论等。通过了解目标市场的满意度和偏好，你可以相应地调整营销和销售策略。

<h3>2. 定价策略</h3>
通过分析竞争对手对类似商品的定价，为你的商品设定最优价格。保持价格竞争力，并根据需要进行调整，以最大限度提升销量和利润。

<h3>3. 商品趋势</h3>
分析商品和类别的受欢迎程度，以及特定商品随时间变化的表现。使用这些数据跟踪销售趋势和库存水平，从而为补货和生产规划做出明智决策。
